# Homebrew NetDIMM (domaine public)

Programmes de [DragonMinded/netboot](https://github.com/DragonMinded/netboot), domaine public
(voir `LICENSE`), copiés depuis WiPiNetbooter 6.1. `deploy/install.sh` les installe dans
`/srv/naomox/homebrew`.

| Fichier | Usage |
|---|---|
| `naomidiag.bin.gz` | diagnostic Naomi (Bornes → Modifier → Maintenance) |
| `netbootmenu.bin[.dark|.light]` | menu de sélection à l'écran de la borne (OSM, pas encore porté) |
